# To-Do List Application

A simple and user-friendly To-Do List Application that helps users manage daily tasks efficiently. The application allows users to create, update, complete, and delete tasks while keeping their workflow organized.

This project focuses on implementing basic task management functionality with a clean interface and easy-to-use features.

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- View completed and pending tasks
- Simple and clean user interface
- Responsive design for different screen sizes

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
